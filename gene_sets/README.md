# Required MSigDB gene sets

Use the human gene-symbol GMT files from **MSigDB v2025.1.Hs**, without renaming them:

- `h.all.v2025.1.Hs.symbols.gmt`
- `c2.all.v2025.1.Hs.symbols.gmt`
- `c5.all.v2025.1.Hs.symbols.gmt`
- `c7.all.v2025.1.Hs.symbols.gmt`

Download the archived version from [MSigDB](https://www.gsea-msigdb.org/gsea/msigdb/) and place the files in this directory. Registration may be required. Do not substitute a newer release when reproducing this workflow.

MSigDB is maintained by the Broad Institute and UC San Diego. Review its [license terms and collection-specific conditions](https://www.gsea-msigdb.org/gsea/msigdb_license_terms.jsp) and follow its [citation guidance](https://www.gsea-msigdb.org/gsea/msigdb/). The public code distribution provides download instructions rather than redistributing these third-party GMT files.
